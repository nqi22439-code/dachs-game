# 🌭 フォルの三軒茶屋大冒険

白いダックスフンドの**フォル**が、三軒茶屋の街を駆けぬける横スクロールアクションゲーム。
夕方のおさんぽ中、ご主人がヒゲの男たちにさらわれてしまった。
ジャーキーを集めて、ヒゲおじさんをやっつけて、ご主人を助けだそう！

**▶️ 遊ぶ： https://nqi22439-code.github.io/dachs-game/**

HTML 1ファイルだけで動きます。ビルドもインストールも不要です。

---

## 操作方法

### パソコン（キーボード）

| キー | 動作 |
|---|---|
| ← → | 移動 |
| Space / ↑ | ジャンプ（長押しで高く跳ぶ） |
| ↓ | しらべる（マンホールにもぐる） |
| R | ステージをやり直す |
| Esc | ステージ選択にもどる |
| O | オープニングをもう一度見る（タイトル画面で） |

### スマホ（タッチ）

タッチ端末では画面にボタンが自動で表示されます。
◀ ▶ で移動、**ジャンプ**ボタンでジャンプ、▼ でしらべる、右上の**もどる**でステージ選択へ。
移動しながらのジャンプ（同時押し）にも対応しています。

iPhone の Safari で開いたあと、**共有 → ホーム画面に追加**しておくと、
アプリのように全画面で起動できます。よこ向きが遊びやすいです。

## ステージ

**3エリア × 3ステージ＝全9ステージ**。各エリアの3ステージ目はボス戦です。
ステージをクリアすると次が開放され、選択画面から好きなステージを選べます。

### 第1エリア　三軒茶屋の商店街（昼）　敵：ヒゲおじさん

| | ステージ | 内容 |
|---|---|---|
| 1-1 | エコー仲見世商店街 | 赤いアーケードと提灯。**かくしステージの入口**あり |
| 1-2 | すずらん通り | すずらん型の街灯が並ぶ商店街 |
| 1-3 | 三角地帯 | 提灯ひしめく飲み屋街。**ボス戦（HP3）** |

### 第2エリア　夕暮れの大通り（夕方）　敵：スーツのヒゲ男（足が速い）

| | ステージ | 内容 |
|---|---|---|
| 2-1 | 茶沢通り | ストライプの日よけが続く商店 |
| 2-2 | 世田谷通り | 世田谷線の黄緑の電車が走る |
| 2-3 | 国道246号線 | 頭上を首都高の高架が横切る。**ボス戦（HP4）** |

### 第3エリア　三軒茶屋の夜（夜）　敵：酔っぱらいのヒゲ男（跳ねてくる）

| | ステージ | 内容 |
|---|---|---|
| 3-1 | クラフトビール サニティ | ネオンの光るビアバー |
| 3-2 | ゴリラビル | 屋上のゴリラが見下ろす |
| 3-3 | キャロットタワー最上階 | **ラスボス戦（HP5）** → クリアで**エンディング** |

### ★ 地下のひみつ通路

ステージ1-1のどこかにマンホールがあります。乗って ↓（スマホは ▼）を押すと地下へワープ。
ジャーキー46個が詰まったボーナス面で、一度見つけるとステージ選択に並びます。

## やり込み

- **★ジャーキー全取得** — ステージ内のジャーキーを取りこぼさずクリアすると、選択画面のカードに★がつきます
- **ベストタイム** — ステージごとの最速クリアタイムを記録。プレイ中もHUDに表示されます
- **クリア率** — 選択画面の上部に「クリア ○/9」「★ジャーキー全取得 ○/9」を表示
- **ベストスコア** — タイトル画面に表示

## 中身

**オープニング（全6シーン）** — 夕方の三軒茶屋でのおさんぽから、ご主人がさらわれ、フォルが駆けだすまで。
初回プレイ時に自動で流れます。タイトル画面の「▶ オープニングを見る」（キーボードなら O キー）でいつでも見返せます。

**エンディング（全6シーン）** — ラスボスを倒すと自動で流れます。ご主人と再会し、
夜の三軒茶屋を並んで歩いて帰り、おうちで山盛りのジャーキーをもらうまで。

**登場キャラクター**

- **フォル** — 主人公。黄色いシャツを着た白いダックスフンド
- **ご主人** — 茶髪のショートパーマにカジュアルな服。さらわれてしまう
- **ヒゲおじさん / スーツのヒゲ男 / 酔っぱらいのヒゲ男** — エリアごとに変わる手下。踏むと倒せる
- **ロン毛のヒゲおやぶん** — 各エリアのボス。モジャモジャのロン毛に濃いヒゲ面、小太りの体に紫のコート

**三軒茶屋の街並み** — 多重スクロールの背景に、ドット絵で描き起こしたおなじみの風景が登場します。

- **キャロットタワー** — にんじん色の本体、上部のセットバック、展望フロア、点滅する航空障害灯
- **ゴリラビル** — 屋上のゴリラのシルエット
- **エコー仲見世商店街** — 赤いアーケードゲートと提灯
- **すずらん通り** — アーチの看板と、すずらん型の街灯
- **三角地帯** — 提灯と縦看板がひしめく飲み屋街
- **茶沢通り** — ストライプの日よけが並ぶ商店
- **世田谷線** — 黄緑の2両編成がゆっくり通り過ぎる
- **国道246号線** — 頭上を横切る首都高の高架と、走り抜ける車のライト
- **クラフトビール サニティ** — ネオンの光る看板とビールジョッキ

**きらきら無敵モード** — ジャーキー10個ごとに発動。8秒間、虹色に光って移動が速くなり、
触れるだけで敵を倒せます。

**その他** — コヨーテタイム・ジャンプ先行入力・可変ジャンプでマリオに近い操作感に。
効果音は Web Audio API で生成しているので音声ファイルは不要です。

## 技術メモ

- 素の HTML / CSS / JavaScript（Canvas 2D）のみ。ライブラリ・外部アセットなし
- スプライトはすべてコード内で矩形を並べて描画（画像ファイルなし）
- 効果音は Web Audio API のオシレーターで生成
- 進行状況は `localStorage` に保存
