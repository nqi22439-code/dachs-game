# 🌭 ダックスの三軒茶屋大冒険

ダックスフンドが三軒茶屋の街を駆けぬける、横スクロールアクションゲーム。
ジャーキーを集めて、ヒゲおじさんをやっつけて、ご主人を助けにいこう！

**▶️ 遊ぶ： https://nqi22439-code.github.io/dachs-game/**

HTML 1ファイルだけで動きます。ビルドもインストールも不要です。

---

## 操作方法

### パソコン（キーボード）

| キー | 動作 |
|---|---|
| ← → | 移動 |
| Space / ↑ | ジャンプ（長押しで高く跳ぶ） |
| ↓ | しらべる（マンホールにもぐる） |
| R | ステージをやり直す |
| Esc | ステージ選択にもどる |

### スマホ（タッチ）

タッチ端末では画面にボタンが自動で表示されます。
◀ ▶ で移動、**ジャンプ**ボタンでジャンプ、▼ でしらべる、右上の**もどる**でステージ選択へ。
移動しながらのジャンプ（同時押し）にも対応しています。

iPhone の Safari で開いたあと、**共有 → ホーム画面に追加**しておくと、
アプリのように全画面で起動できます。よこ向きが遊びやすいです。

## 中身

**三軒茶屋の街並み** — 多重スクロールの背景に、ドット絵で描き起こしたおなじみの風景が登場します。

- **キャロットタワー** — にんじん色の本体、上部のセットバック、展望フロア、点滅する航空障害灯
- **ゴリラビル** — 屋上のゴリラのシルエット
- **エコー仲見世商店街** — 赤いアーケードゲートと提灯
- **三角地帯** — 提灯と縦看板がひしめく飲み屋街
- **世田谷線** — 黄緑の2両編成がゆっくり通り過ぎる（ステージ②）

**ボス：ロン毛のヒゲおやぶん**（ステージ③） — サングラスに巨大な口ヒゲ、紫のトレンチコート。
追いかけてきて飛びかかってきます。3回踏むと撃破。倒すまでご主人には近づけません。

**きらきら無敵モード** — ジャーキー10個ごとに発動。8秒間、虹色に光って移動が速くなり、
触れるだけで敵を倒せます。

**かくしステージ** — ステージ①のどこかにマンホールがあります。乗って ↓ を押すと…？

**その他** — コヨーテタイム・ジャンプ先行入力・可変ジャンプでマリオに近い操作感に。
効果音は Web Audio API で生成しているので音声ファイルは不要です。

## 技術メモ

- 素の HTML / CSS / JavaScript（Canvas 2D）のみ。ライブラリ・外部アセットなし
- スプライトはすべてコード内で矩形を並べて描画（画像ファイルなし）
- 効果音は Web Audio API のオシレーターで生成
- 進行状況は `localStorage` に保存
